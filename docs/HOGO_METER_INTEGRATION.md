# hogo-meter 連携の引き継ぎ

## 目的と現状

[hogo-meter](https://github.com/ysogabe/hogo-meter) と連携し、Echo Show 5 の常設画面でお世話の最終実施時刻・経過時間を確認し、タッチで記録できるアプリを作ります。操作画面の構成や実装方式、API 契約はまだ確定していません。

名前や項目数を固定せず、連携先で管理されている項目名・設定を尊重する方針です。時計からの復帰タッチで記録を送らない要件は [IDLE_CLOCK.md](IDLE_CLOCK.md) を引き継ぎます。

## 実装前に決めること

1. 新しい Echo Show 5 の世代、Android 化の状態、OS/API レベル、解像度、ADB 接続を確認する。
2. 既存デバイスの記録を操作するパネルか、新しい記録端末として登録するかを決める。登録済み機器の認証情報を流用しない。
3. ネイティブ UI と既存ダッシュボードを利用する方式を比較し、ログイン・セッション更新・専用端末での操作性を確認する。
4. 連携元にある利用者向けと実機向けの認証・認可の区別を確認し、採用する API、世帯への所属、登録・解除手順を確定する。Miharashi の LAN API や Bearer トークンを前提にしない。
5. 項目一覧、最終記録、経過時間、必要ならスケジュール状態の取得方法・更新間隔を決める。SSE の有無は未確認。
6. 記録要求の形式、時刻の基準、応答、取り消し、重複送信対策、オフライン時の表示・再送方針を決める。通信失敗時に記録完了とは表示しない。
7. 新アプリ用の applicationId、設定の保存方法、ビルド・導入・更新方法を確定する。

接続先・資格情報は利用時に設定し、公開リポジトリや配布 APK に共通の秘密情報を含めません。開発時はテスト用のデータを使い、本番のお世話記録を書き換えずに通信を検証できる環境を用意します。
