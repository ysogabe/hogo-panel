1. ホームで気づく

左は定期予定、右は直近のお世話。期限超過を先に表示し、日々の記録にもすぐ手が届きます。

2. 今回の実施を確認

「実施した」「あとで」「見送る」を区別。今回の完了で、来週・来月まで完了にはしません。

3. 時計中は控えめに

通知では件数だけ。最初のタッチは復帰専用で、記録ボタンへ触れ抜けません。
