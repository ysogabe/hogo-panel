# 投薬を思い出すパネル — 要求（改訂3）

2026-10-18。[画面案](prototype.html) / [設計](design.md)。ユーザーの希望で汎用予定管理案を簡略化した。変更前の案はGit履歴に残る。

## 目的

月に一度のフィラリア・フロントライン等を、画面を見て思い出す。詳しい説明や次回日付は不要。予定日の2日前から警告する。普段はhogo-meterだけを表示し、警告期間にだけ画面を変えて気づけるようにする。薬名・周期・予定日は利用者の設定を使い、今回のモックは架空データとする。

## 要求

- **R1 必須:** 普段は日々のお世話3項目を横一列に大きく表示し、薬名を一切出さない。警告期間だけ、左に対象薬・右に日々のお世話の配置へ変える。説明文、予定日、次回日付、取得元、件数、週次/月次タブは主画面に出さない。
- **R2 必須:** 予定日の2暦日前から「そろそろ」、当日は「今日」、過ぎても記録がなければ「未確認」。文字・色で区別し、3日前までは投薬カードを出さない。
- **R3 必須:** 薬名を押すと、薬名と「戻る」「やった」だけの確認を出す。開くだけ・閉じるだけでは実施済みにしない。確認を開いた直後450msは実施を受け付けない。
- **R4 必須:** 「やった」でその回だけ記録し、カードと時計の警告から消す。残りがあればその薬だけ、全て実施したら普段の画面に戻る。8秒の取消で対象の警告を戻せる。済カードや次回日付は出さない。
- **R5 必須:** hogo-meterの項目は名前と経過時間だけ。押すと短い確認を出す。投薬と日々のお世話を相互に自動記録しない。
- **R6 必須:** 時計中は警告対象の薬名だけを小さく添える。最初のタッチは復帰専用。実施済みの薬名は時計の警告から消える。
- **R7 必須:** 公開モックは架空データのみ。外部接続・永続保存・Android実装は行わない。リロードで初期化する。
- **R8 あると良い:** 週次の用事も同じ「名前と短い状態」で扱える。設定・過去履歴・接続情報の詳細は主画面から分けて後段で検討する。

## 受け入れ条件

- **AC1（R1）:** 普段は日々のお世話3項目だけ。2日前で対象薬が現れ、色だけでなく配置が変わる。実施後は対象薬が消え、全て記録すると普段の画面と同じになる。
- **AC2（R2）:** 通常・2日前・当日・翌日を再現し、各状態が指定どおり変わる。2日前は48時間でなく対象地域の暦日で判定する。
- **AC3（R3, R4）:** 開く・戻る・外側を押すだけでは未実施。「やった」で対象カードだけ消え、取消でその警告が戻る。他の薬・別の回を変更しない。開いた直後の2回目のタップも記録されない。
- **AC4（R5）:** 日々のお世話の記録と取消で投薬の状態が変わらない。
- **AC5（R6）:** 時計に警告対象の薬名だけが出る。最初のタッチで記録が増えずホームへ戻る。
- **AC6（R7）:** 構文・枠内配置・主要操作をブラウザで確認し、実機の輝度や指のジェスチャーの検証とは区別する。

## 範囲と未決事項

HTML 段階は簡略UIのHTMLモックまで。R7とAC6の「Android実装は行わない」はこの段階の記述で、2026-10-18のユーザー承認により Android の操作モック実装（架空データ・メモリ内のみ・外部通信なし）へ進めた。実装状態は [設計の Android 節](design.md#android-操作モック) と [確認記録](verification.md) を参照。その後にhogo-meterとGoogleを連携する。投薬方法を案内する機能は作らない。音、夜間、複数の猫、3つ以上の定期項目、家族間の実施共有先は別途決める。
