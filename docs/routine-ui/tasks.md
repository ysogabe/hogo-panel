## Android段階の確認

HTML段階のR7・AC6の「Android実装は行わない」「ブラウザで確認」は、今回の実装承認により段階を進める。外部通信なし・架空データのみ・永続保存なしを維持する。Androidのプロセス終了で初期化し、試用中は画面外のシナリオ選択からもリセットできる。通常のホームにデバッグ用の説明やボタンを並べない。

AC1–AC5の操作・表示はAndroidでも満たし、AC6は既存HTML検証に加えAndroidのビルド、単体試験、960×480実機の表示・操作を別々に記録する。実機未確認の項目を検証済みと扱わない。Google・hogo-meter連携、実際の投薬予定・記録はこの段階では扱わない。
