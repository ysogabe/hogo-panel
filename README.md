# Hogo Panel

[hogo-meter](https://hogo-meter-intro.akebi.dam-lab.work) と連携する、Android 化した Echo Show 5 向けのお世話パネル。

お世話の最終実施時刻・経過時間の確認と記録を、常設のタッチ画面から行うためのアプリを開発します。無操作時には低輝度のフリップ時計を表示する方針です。

## 現在の状態

3段階あります。

- **時計だけの PoC（0.1.0）:** 起動直後から低輝度のフリップ時計だけを表示します。ビルド・単体テスト16件・lint を確認し、Android 11 の Echo Show 5 へ Wi-Fi ADB 経由で導入して全画面表示と JDWP を確認しました。範囲は [ビルドと端末導入](docs/BUILD.md#実機検証結果2026-10-18) を参照してください。
- **操作モック（0.2.3、アプリ表示名 Hogo Panel Mock）:** 承認済みの [HTML 画面案](docs/routine-ui/prototype.html) を Android のネイティブ画面にした、**架空データだけ**の操作モックです。普段はお世話3項目、薬の予定日の2暦日前から薬カード、確認と8秒の取消、3分無操作か時計ボタンで既存のフリップ時計、画面外のシナリオ選択を備えます。0.2.1 から、当日・未確認の薬カードだけが約2.4秒周期でゆっくり明滅します（2日前と時計は静止）。0.2.2 から、時計の輝度は現地時刻で日中（6–18時）0.60・夜（18–22時）0.20・深夜（22–6時）0.05（従来値）に切り替わります。0.2.3 から、時計は約1.3倍（814×281）になり、直下に現地の日付と曜日（`2026/10/19（月）`）が時計と同じ幅で出ます。メモリ内のみで、通信・保存・新しい権限・HOME 指定・自動起動はありません。操作と試し方は [操作モックの試用](docs/routine-ui/design.md#android-操作モック) を参照してください。
- **API モード（0.3.0）:** 操作モックに、PC 上の Mock API（`tools/mock-hogo-meter/`）から投薬予定を取る評価用の経路を足しました。hogo-meter に足す機器向け API の案（v0）の形と、パネルの表示を実機とブラウザで評価するためのものです。接続設定（`files/api-config.json`）を `adb shell run-as` で置いたときだけ有効で、置かなければ今までのシナリオの操作モックのままです。`INTERNET` 権限と 127.0.0.1 だけに平文を許す設定は debug ビルドだけにあり、release にはありません。取得できない・古い・未接続などの状態は、警告なしと区別して小さく出します。2026-10-22 に Wi-Fi ADB の Show 5 とブラウザで評価しました。手順は [Mock API の README](tools/mock-hogo-meter/README.md)、結果と API で直したほうがよい点は [評価記録](docs/calendar-mock/verification.md) を参照してください。Google・hogo-meter への実際の接続、実施の送信はありません。
- **当日だけ出す予定（0.4.0）:** API の回に任意の `dayOnly` と、アイコン `trash`（ゴミ箱）を足しました。`dayOnly` の回は予定日の当日だけ薬と同じカードに出し（前日までの予告も翌日以降の持ち越しもしません）、「やった」で記録・取消できます。Mock API は、管理側が `tools/mock-hogo-meter/local/`（Git の管理外）に置いたゴミ収集の定義から、この回を薬の回に加えて返します。単体テストは 298 件です。Show 5 実機（Wi-Fi ADB）で、当日のゴミの回がゴミ箱のアイコン付きの「今日」のカードと確認の画面に出ること、翌日の回が予告されず前日の回が持ち越されないことを確認しました。

操作モック0.2.3は、ビルド・単体テスト112件（時計の既存16件を含む）・lint（エラー0件、既存の警告3件）を確認しています。Show 5実機でも、ADBのタッチ入力とスクリーンショットで主要表示・遷移、3分の待機、時計の輝度指定と復帰を確認しました。当日・超過の約2.4秒の明滅は0.2.1の実機動画で確認しています。0.2.2では夜の時間帯の輝度0.20、ホーム・背面での解除、時計への再適用を実機で確認しました。0.2.3の拡大した時計と日付・曜日は実機画像で左右端の一致を確認し、薬の札2件と重複しないこと、前面復帰後の再表示も確認しました。各境界と全時間帯は単体テストで検証し、実時刻での境界通過や肉眼の見やすさ・長時間の残像は未確認です（スクリーンショットの画素ではバックライト輝度を測れません）。[検証記録](docs/routine-ui/verification.md)に範囲をまとめています。実際の投薬予定・Google・hogo-meter との接続、設定画面はありません。APK は配布せず、[ビルドと端末導入](docs/BUILD.md) の手順で作ります。

## 対象端末

Android 化した Echo Show 5 を対象にしています。今回の実機は LineageOS 18.1 / Android 11 / 960×480、32ビット ARM です。標準の Echo Show OS へそのまま APK を導入できるという意味ではありません。

## 名前

リポジトリ名とフォルダ名は `hogo-panel`。連携元の `hogo-meter` と共通の `hogo` に、常設の確認・操作画面を表す `panel` を組み合わせています。`hogo-meter-show5` は端末名に用途を固定し、`hogo-meter-android` は常設パネルという役割が伝わりにくいため、こちらを採用しました。
